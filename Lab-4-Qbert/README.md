## Tasks covered

1. Correct the pyramid projection arithmetic so the pyramid is symmetric.
2. Return a different cube colour palette by level.
3. Trigger a completion bonus only when a cube first reaches its target stage.
4. Award an extra life at the configured score threshold.

## Running the game

Python 3.10+ is recommended.

```bash
pip install pygame
python game.py
```

Controls: arrow keys hop diagonally, `R` resets, and Space continues after a cleared level.
